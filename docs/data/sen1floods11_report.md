**Why two schemes.** The official train/val/test splits draw chips from the same flood events (only Bolivia is held out), so neighbouring, correlated chips can appear in both training and test. `geo_holdout_v1` holds out entire events (test: Bolivia, Mekong, Ghana; val: Pakistan, Spain) to measure generalisation to unseen regions. Leave-one-event-out folds (11) are written to `splits/loeo/` for Phase 8.

## Observations
- Strong class imbalance: water is a minority class in every event → use Dice/Lovász or weighted BCE and report flood-class IoU, not pixel accuracy.
- Large ignored fractions in some events (pixels annotators marked as not valid) → metrics must exclude ignore pixels.
- S1 NaNs (pixels with no radar coverage) exist and are masked from loss and metrics.
